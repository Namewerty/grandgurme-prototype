# Медиафайлы прототипа

Положите файлы по этим путям — прототип подхватит их без правок кода.
Пока файла нет, на его месте рисуется заглушка с именем файла и пропорцией.

## video/

| Файл | Требования |
|---|---|
| `hero-brand.webm` | ролик бренда с grandgurme.ru без перекодирования: VP9, 1280×720, 25 к/с, 20,3 с, без звука, 3,4 МБ |
| `hero-brand.mp4` | тот же ролик: H.264 High, CRF 23, `+faststart`, без звука, 3,3 МБ |
| `hero-brand-poster.jpg` | первый кадр ролика, 1280×720 |
| `hero-brand-portrait.webm` | центральный кадр 4:5, 576×720 (смещение 352 px слева), VP9, 1,2 МБ — телефон в портрете |
| `hero-brand-portrait.mp4` | тот же кадр, H.264, 1,6 МБ |
| `hero-brand-portrait-poster.jpg` | первый кадр вертикального ролика, 576×720 |

В финале ролика (17,8–20,3 с) по центру кадра стоит золотой логотип. При замене
ролика зона логотипа и раскладка первого экрана пересчитываются — см. README
в корне, «Первый экран: ролик бренда».

Ролик производства больше не нужен: секция «Происхождение», где он стоял,
удалена с главной. Лежащий в папке `production.mp4` можно убрать.

## caviar/ — квадрат 1400×1400

Вид сверху на открытую банку. У всех четырёх одинаковый свет и фон.
Порядок в ряду секции: белуга → осётр → севрюга → белуга и стерлядь.

`caviar-beluga.jpg` · `caviar-osetra.jpg` · `caviar-sevruga.jpg` · `caviar-sterlet.jpg`

Кадров стало четыре вместо шести: по выгрузке 1С в ассортименте четыре вида
осетровых и девять линеек внутри них. Бестера нет вовсе, «Роял Белуга» —
линейка внутри белуги, поэтому `caviar-bester.jpg` и `caviar-royal-beluga.jpg`
больше не нужны и их можно убрать. Файл `caviar-sterlet.jpg` снят как икра
стерляди; отдельной стерляди в ассортименте нет, есть купаж «Белуга и
стерлядь SELECTED» — при пересъёмке заменить файл, имя оставить прежним.

Эти же четыре кадра стоят на всех 52 карточках чёрной икры в каталоге:
внутри вида банка одна и та же, отдельных пэкшотов на каждую фасовку не нужно.

## nav/ — карточки каталожной панели, квадрат 800×800

Самая большая пачка: по кадру на каждую подкатегорию каталога. Перечень ниже
собирается скриптом (`npm run media`) прямо из `src/data/catalog.js` — править
его руками не нужно, дерево каталога ещё меняется.

Кадры мелкие (в панели карточка около 165 px шириной), поэтому снимать нужно
КРУПНО — один продукт по центру, без композиций и без подписей на кадре:
на такой величине читается только силуэт.

Имя файла собирается из слагов: `<категория>-<подкатегория>.jpg`. Оба слага
живут в `src/data/catalog.js`; переименуете подкатегорию — переименуйте файл,
иначе на карточке останется серая заглушка с именем.

Присылайте квадрат — панель обрезает его до 4:3 средствами CSS. Свет и фон
одинаковые у всех кадров: это сетка, разнобой в ней виден сразу.

## brand/

`logo.svg` (тёмный, для плотной шапки) · `logo-white.svg` (для прозрачной шапки над hero) · `favicon.svg`

### Коллаж блока «О бренде»

| Файл | Размер | Пропорция | Что на кадре |
|---|---|---|---|
| `boutique-main.jpg` | 1200×1600 | 3:4 | интерьер флагманского бутика, вертикальный кадр |
| `boutique-detail-01.jpg` | 1200×1600 | 3:4 | зал или витрина, вертикальный |
| `boutique-detail-02.jpg` | 1600×1200 | 4:3 | продукт или подача, горизонтальный |

Три кадра — один сюжет и один свет: это коллаж, а не три фотографии рядом.
Разные форматы в нём держат асимметрию, разный свет её сломает.

На `boutique-main.jpg` нижняя четверть уходит под затемнение с курсивной
врезкой «Гастрономия ресторанного уровня — дома» — смысловой центр кадра
держите выше середины.

## alt2/ — кадры альтернативной главной 2 (`/alt2`)

Черновая страница для показа, подробности — в README в корне, «Альтернативная
главная 2 (`/alt2`)». Откуда взят каждый кадр, размеры и оговорки по правам —
в [`alt2/ИСТОЧНИКИ.md`](alt2/ИСТОЧНИКИ.md).

| Папка | Что | Где на странице |
|---|---|---|
| `hero/` | пять кадров разделов: чёрная и красная икра, рыба (постер ролика), морепродукты, подарки | первый экран «Витрина разделов»; шестой кадр — `brand/boutique-main.jpg` |
| `types/` | девять пэкшотов банок на белом фоне, `tin-<слаг линейки>.jpg` | «Характер икры»: малый круг у большого, у паюсной — большой круг |
| `origin/` | кадры шагов производства икры и рыбы | «Происхождение», по кадру на шаг |

⚠ `origin/origin-voda.jpg` и `origin/fish-kozha.jpg` — заглушки из ролика
бренда до фото фермы на Каспии и северной реки. `origin/fish-razdelka.jpg`
лежит в запасе: в шагах рыбы его нет. Права на кадры из ресторанов
(`hero-moreprodukty.jpg`, `hero-krasnaya-ikra.jpg`) подтвердить у заказчика
до переноса на боевой сайт.

Кадры лупы в «Характере икры» — те же `caviar/caviar-*-detail.jpg`, что
и в галерее карточки товара; отдельных файлов под `/alt2` для них нет.
