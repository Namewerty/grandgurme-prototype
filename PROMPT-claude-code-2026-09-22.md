2. `git pull --ff-only`. Запомни `git rev-parse HEAD` — `main` до бандлов.
   Ожидается `39b83d6`.

3. Применить бандлы строго по порядку имён:

   ```
   git fetch _patches/2026-09-21-roliki.bundle HEAD && git merge --ff-only FETCH_HEAD
   git fetch _patches/2026-09-22-katalog.bundle HEAD && git merge --ff-only FETCH_HEAD
   ```
