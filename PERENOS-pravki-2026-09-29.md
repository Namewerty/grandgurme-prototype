Записка, а не задание: в этой задаче стенд не трогали (`stand:deploy`
и `stand:php` не запускались). Что сделано в прототипе — README:
«Корзина и оформление → Доставка по зонам и время „к столу“», «Каталог:

то, что на стенде рисует PHP и поэтому само не поменяется, и одна ловушка.

## 0. Ловушка: кольцо прогресса

`footer.php` печатает `gg_progress_ring()` (`include/fn.php`), а стилей
кольца в сборке больше нет. Чтобы на стенде внизу не встал голый SVG, в
`src/bitrix/stand.css` стоит `#progress-ring { display: none; }`.
При переносе: убрать вызов из `footer.php` и функцию из `fn.php`,
затем удалить правило из `stand.css`.

## 1. Фильтр по цене (каталог на сервере)

Серверный каталог (`catalog.section/gg`) рисует фильтры ссылками
и `<details class="drop">`. Пилюли «Цена» там нет ни у одного раздела.
Нужно: диапазон по `CATALOG_PRICE` (или свойству цены из выгрузки) с тем же
правилом «цен мало» — меньше двух разных цен в выборке, пилюля неактивна
с подсказкой «Цены уточняются — спросите менеджера»; позиции без цены
уходят из суженного диапазона; сортировки «Сначала дешевле / дороже»
с позициями без цены в конце. Разметка поповера — как в `rangeMarkup`
(`src/js/catalog/range.js`), стили уже в `components/filters.css`
(подключён в `src/bitrix/main.js`).

## 2. Доставка

* **Зоны и цены** — `src/data/delivery-zones.js`; полигоны —
  `public/data/delivery-zones.geojson` (нужно положить в `/local/gg-stand/`
  или отдавать из шаблона). Службу доставки завести с расчётом по зоне:
  свойство заказа «Зона» (`ttk`, `mkad`, `zone3`…`zone6`) и стоимость
  = цена зоны, 0 при сумме товаров от порога; при двух отгрузках — по сумме
  каждой. Свойство «Время к столу» (HH:MM) рядом с интервалом.
* **Оформление** на стенде — серверная страница с гидратацией
  (`src/bitrix/purchase-hydrate.js`). Поле «Зона доставки», строки
  «Доставка сейчас / под заказ», «Бесплатно», капсулу «К точному времени» —
  по образцу `src/js/checkout/checkout-page.js`; поле «Город» убрать.
  Геокодер — HTTP-геокодер Яндекса со своим ключом (на сервере или
  `VITE_YANDEX_GEOCODER_KEY` при сборке), без ключа — ручной выбор.
* **Интервалы** — из окна 10:00–18:00: 10:00–14:00, 14:00–18:00,
  «В течение дня (10:00–18:00)». Вечерний убрать.
* **Оплата** — картой онлайн и СБП; «При получении» — только заказ
  с коробками под заказ (см. вопрос в README).
* **Адреса кабинета** (`include/account.php`) — поле зоны, `zone`
  в записи адреса; сохранённый адрес подставляет зону на оформлении.
* **Корзина** — строка «До бесплатной доставки … — N ₽» и полоса
  (`src/js/cart/cart-page.js`, `paintFree`), зона — из основного адреса.
* **`/delivery`** — таблица зон и карта конструктора вместо прежних
  плейсхолдеров, без «Регионов России», минимальной суммы и оплаты курьеру
  (`src/data/delivery.js`, разметка — `deliveryBody` в `src/page.js`).

## 3. Каталожная панель (`include/fn.php`, `gg_catalog_panel`)

На стенде плитки — подразделы 1С из инфоблока. Состав с 29.09.2026 —
не подразделы, а плитки-фильтры (`src/data/catalog.js`, `subFilters`
в `src/data/facets.js`):

* чёрная икра — восемь линеек, пэкшоты банок
  (`/media/alt2/types/tin-*.jpg`, класс `navcard--pack`), под названием
  зерно из `src/data/caviar-lines.js`; ссылки `?sub=<линейка>` →
  фильтр по свойству сорта;
* красная икра — кета, горбуша, кижуч, нерка (свойство вида);
* рыба — две подписанные четвёрки (`.megagroup`, `.megagroup__label`);
* колонки сетки по числу карточек — `style="--cols: N"` у `.megagrid`;
* карточка без кадра — `.navcard__visual` с `.navcard__stub` (название,
  число позиций) под медиа-слотом. Пока PHP её не рисует, стили заглушки
  на стенде не срабатывают (они привязаны к `.navcard__visual`), и кадр
  без файла остаётся прежней подписью с именем файла.

Старые адреса `?sub=beluga`, `?sub=fasovka-50` и т. п. на стенде должны
открываться с тем же фильтром — разошлись по рекламе.

## 4. Цена за килограмм

Сетка `catalog.section/gg`, карточка `catalog.element`, подсказки поиска
(ответ сервера — готовая строка цены, туда добавить «/кг»), корзина:
рядом с ценой мелко «12 900 ₽/кг». Коробки — цена за кг из выгрузки как
есть, остальное — цена / вес × 1000 до рубля; нет цены или веса — строки нет
(`perKgText` в `src/js/catalog/model.js`). Классы `product__per-kg`,
`pbuy__per-kg`, `srow__per-kg`, `cart-line__per-kg` — стили в сборке.
Строка коробок на карточке больше не пишет цену за 100 г
(`product-copy.js → boxes.stockLine`); `box-hydrate.js` берёт свои тексты
из шаблона — поправить там же.
