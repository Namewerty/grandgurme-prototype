# Финальные скриншоты

Сняты с собранного прототипа (`npm run build` + `npm run preview`) через
headless Chrome по CDP. При съёмке эмулируется `prefers-reduced-motion: reduce` —
Lenis не поднимается, reveal сразу в конечном состоянии. Так в кадр попадает
макет, а не случайная фаза анимации. Исключения — кадры, где показано само
поведение: `desktop-why-ТРЕТИЙ-ПУНКТ.png`, `desktop-shop-*`, виджет эксперта.

Мобильные кадры сняты с эмуляцией мобильного устройства, поэтому на них
видно именно тач-режим: пейджер лент скрыт, кнопка «в корзину» показана всегда.

Кадры секций сняты прокруткой к верху секции с отступом на высоту липкой
шапки — так же, как это делает настоящий переход по якорю (см. `scroll.js`).

Тема ставится явно перед каждым кадром (`localStorage.gg-theme`), а не
наследуется от предыдущего: иначе один тёмный кадр окрашивает весь прогон.
